# Lycan

Kendi sunucuların ve bilgisayarların için açık kaynak tehdit avcısı. Geliştirme aşamasında.
Site: https://lycansoc.com

> Yalnızca sahibi olduğun ya da yazılı izin aldığın sistemlerde kullan.

## Geliştirme ortamı

```
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -e .
lycan version
```
